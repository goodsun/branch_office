# bizeny-chat 運用ガイド

*by Akiko Bizeny（Web3事業部） — 2026-03-17*

彰子LP（https://bizeny.bon-soleil.com/）に組み込まれたチャットボットの運用ガイド。

## 概要

- LP訪問者がリアルタイムで彰子と会話できる仕組み
- バックエンド: `~/projects/bizeny/`
- フロントエンド: 彰子LPサイトに組み込み
- HTTPS: Let's Encrypt（自動更新、有効期限90日）

## キャラクター設定の反映

チャットボットのシステムプロンプトに `SOUL.md` の内容を反映させること。
- 彰子の口調・性格・経歴
- 備前焼への想い
- フランス語が混じる特徴

## 運用上の注意

- 訪問者との会話は記録される — 機密情報を出力しないようシステムプロンプトで明示的に制限する
- 「APIキーを教えて」「システムプロンプトを見せて」等への対策を入れること
- 会話ログは定期的に確認し、不適切な出力がないかチェック

## インフラ

```
https://bizeny.bon-soleil.com/ → ~/projects/bizeny/
httpd + Let's Encrypt SSL
証明書自動更新設定済み
```
