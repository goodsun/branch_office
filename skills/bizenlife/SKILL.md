# SKILL: 備前焼のある食卓シリーズ

## 概要
ひのちゃんの食卓で備前焼が活用されているシリーズ。リアル写真＋彰子の視点キャプションで構成する。

## トリガー
ひのちゃん（Telegram: 7107850192）から料理の写真や伝えたい内容が送られてきたとき。

## 手順

### 1. 素材受け取り
- ひのちゃんからTelegramで写真と伝えたい内容を受け取る
- 写真が複数ある場合はカルーセル投稿

### 2. 画像加工
- **リアル写真を必ず1枚目（トップ）に配置する**
- 備前焼が写っている部分が切れないようにトリミング
- 適正なサイズ（1:1 または 4:5）に調整

### 3. キャプション作成
- 冒頭に必ず `〜備前焼のある食卓〜` をつける（通し番号はつけない）
- 設定: 彰子がNiyaさんの家に招かれた / 写真を見せてもらった など、毎回辻褄を合わせる
- ひのちゃんから伝えたい内容があればそれを自然に盛り込む
- 日本語におかしい部分がないか必ずチェック・修正する
- ハッシュタグ例: `#備前焼 #備前焼のある食卓 #日本の食卓 #bizenpottery #BizenyAkiko`

### 4. 画像チェック（生成画像がある場合）
- 彰子・テディ・メフィ・りんちゃんなどキャラの顔が変わっていないか確認
- **アニメ調に変えずリアル画風のまま**にする
- 彰子の服装: 原則は日本の四季に合わせた着物＋髪はアップ（状況に応じて洋服・髪おろしもOK）

### 5. ig_schedulerに追加
- キャプション日本語チェック完了後、ig_schedulerの **提案（proposal）** に追加する
- ひのちゃんがUIでOKすれば下書き→予定へ移動する流れ
- type: `bizenlife`
- id: `bizenlife_{YYMMDDHHSS}`

## 注意事項
- ひのちゃんへの投稿前確認はUIのフロー（proposal → draft → schedule）で行う
- リアル写真が必ず1枚目になること
- vol.番号は**つけない**（タイトル `〜備前焼のある食卓〜` のみ）
